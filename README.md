# Kvartira.ru

Веб-сервис подбора и аренды квартир на Flask. Пользователи могут регистрироваться, просматривать каталог квартир и оставлять заявки на аренду, а администратор — одобрять или отклонять заявки через админ-панель.

> Проект. Разработан на Python + Flask с базой данных SQLite.

---

## 🔹 Возможности

### Для пользователей
- Регистрация и вход в аккаунт (пароли хранятся в зашифрованном виде)
- Просмотр списка доступных квартир (адрес, цена, количество комнат, фото)
- Оставление заявки на аренду: желаемый адрес, цена, количество комнат
- Просмотр своих заявок и их статуса: *На рассмотрении / Одобрено / Отклонено*
- Обратная связь


### Для администратора (`/admin`)
- Вход в админ-панель
- Список всех заявок от пользователей
- Одобрение и отклонение заявок
- Выход из админ-панели

## 🚀 Быстрый старт

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/TorValum/Kvartira.RU.git
cd Kvartira.RU
```

### 2. Создайте и активируйте виртуальное окружение

```bash
python -m venv venv
# Windows
venv\Scripts\activate
# Linux / macOS
source venv/bin/activate
```

### 3. Установите зависимости

Проект использует Flask и Flask-Login:

```bash
pip install flask flask-login
```

### 4. Инициализируйте базу данных

Создайте таблицы из файла `sq_db.sql`. В интерактивном режиме Python:

```python
from app import app, connect_db

with app.app_context():
    db = connect_db()
    with app.open_resource('sq_db.sql', mode='r') as f:
        db.cursor().executescript(f.read())
    db.commit()
    db.close()
```

Или воспользуйтесь任何 клиентом SQLite (например, DB Browser for SQLite), открыв `sq_db.sql`.

> 💡 Файл `bd.db` уже может лежать в репозитории — в этом случае инициализация не требуется.

### 5. Запустите приложение

```bash
python app.py
```

Приложение будет доступно по адресу: **http://127.0.0.1:5008/**

## 🔗 Основные маршруты

| Маршрут | Описание | Доступ |
|---------|----------|--------|
| `/` | Главная страница со списком квартир | Все |
| `/register` | Регистрация нового пользователя | Все |
| `/login` | Вход в аккаунт | Все |
| `/logout` | Выход из аккаунта | Авторизованные |
| `/contact` | Обратная связь | Авторизованные |

| `/admin/zayvka-reject/<id>` | Отклонить заявку | Администратор |

## 🔐 Админ-панель

Для входа в админку перейдите на `http://127.0.0.1:5008/admin/login` и используйте учётные данные, заданные в `admin/admin.py`:

- Логин: `admin`
- Пароль: `12345`

## 🗄 База данных

Ключевые таблицы (схема в `sq_db.sql`):

- `users` — зарегистрированные пользователи (имя, email, хэш пароля)
- `Kvartiра` / `Kvartiras2` — объявления о квартирах (адрес, цена, комнаты, фото, ссылка)
- `Zayavka2` — заявки на аренду (желаемый адрес, цена, комнат, статус, пользователь)
- `mainmenu` — пункты меню сайта

Функция `migrate_db()` в `app.py` автоматически доабвляет недостающие колонки (`status`, `user_id`, `time`) в таблицу `Zayavka2` при запуске.
